3. REGOLE ARCHITETTURALI & VALIDAZIONE
================================================================================
- Zero Marchi Registrati: mantenere nomi originali per i prodotti; i riferimenti circuitali non sono nomi commerciali dei plugin.
- Accorpamento Versioni: unificare le revisioni storiche della stessa macchina in un unico plugin con selettore dedicato (es. 1176 Rev A/D/E/F, DBX 160VU/X/A, API 2500/2500+, API 550A/B); non unificare hardware intrinsecamente diversi.
- Conformità Obbligatoria (vcinst.md Sez. 4): ogni plugin espone `Channel Setup` manuale (`Auto` + `Mono..7.1`); tutti i processori di dinamica espongono `SC Source`, `SC Listen`, `SC HPF/LPF/Bell`, `Channel Mode` (`Stereo Link / Dual Mono / Mid-Side`) e `Mix`.
- Documentazione Sincronizzata: aggiornare ogni scheda TXT insieme all'API e ai test del relativo componente.
