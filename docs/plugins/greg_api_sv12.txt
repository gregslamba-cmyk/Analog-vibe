ID: greg_api_sv12
Nome plugin: Greg SV12
Categoria: compressore analogico 500 Series
Stato: pianificato
Riferimento hardware: API Select SV12, circuito originale ATI Paragon.

Caratteristiche hardware:
- Mono per modulo, due unita' linkabili con somma di potenza RMS per stereo.
- Threshold -40..+15 dBu; ratio 1:1..10:1; makeup 0..+20 dB.
- Attack adattivo 10..40 ms e release adattivo 30..400 ms, entrambi program/control-dependent.
- Hard/soft knee; sidechain Flat/THRUST; detector THRUST brevettato.
- Banda ±0.5 dB 20 Hz–30 kHz; massimo livello +24 dBu.

Confrontare con SR22: il costruttore li riconduce alla stessa famiglia ATI Paragon, ma il formato e le specifiche non sono identici.
