ID: greg_api_525a
Nome plugin: Greg 525A
Categoria: compressore/limiter FET discreto
Stato: pianificato
Riferimento hardware: API 525A, revisione evoluta del compressore 525.

Caratteristiche hardware:
- Attack variabile 15 us..15 ms; release discreto a sette valori: 0.05, 0.1, 0.2, 0.3, 0.5, 1 e 2 s.
- Compression 2:1 e Limit 20:1; Ceiling accoppia threshold e makeup gain.
- Percorso discreto con op-amp 2510/2520, trasformatore API in uscita e bypass hardware.
- Riduzione massima 25 dB; risposta ±0.5 dB 20 Hz–40 kHz.

E' un modello distinto dal 525: non riusare attack fisso, release frequency-dependent o De-Ess del 525 senza commutazione esplicita.
