ID: greg_api_2500
Nome plugin: Greg 2500
Categoria: compressore stereo VCA da bus
Stato: implementato; accorpa le versioni API 2500 e API 2500+ con selettore di versione
Riferimento hardware: API 2500 e API 2500+ Stereo Bus Compressor:
- Profilo 2500: classico compressore stereo da bus a due canali; topologia Old (feedback) o New (feed-forward); filtro brevettato THRUST; knee Soft, Medium, Hard; auto o manual makeup gain; soglia -20..+10 dBu; link stereo regolabile a percentuale.
- Profilo 2500+: aggiunge il circuito Mix/Blend con selettore per Crossfade o Compressione Parallela, headroom estesa a +32 dBu bilanciata a trasformatore e risposta 20 Hz–50 kHz.

Caratteristiche e controlli:
- Selettore di versione: 2500 Classic vs 2500+.
- Controllo Mix/Blend (attivo su profilo 2500+): OFF, Crossfade (Dry/Wet lineare), Parallel (somma dry + wet).
- THRUST: Normal, Med, Loud (filtro pre-detector ad enfasi delle alte e protezione delle basse).
- Tone Type: Old (feedback smooth stile vintage) vs New (feed-forward punchy e preciso).
- Knee: Soft, Medium, Hard.
- Ratio: 1.5:1, 2:1, 3:1, 4:1, 6:1, 10:1, infinito:1.
- Attack: 0.03, 0.1, 0.3, 1, 3, 10, 30 ms. Release: 0.05, 0.1, 0.2, 0.5, 1, 2 s e Auto.
