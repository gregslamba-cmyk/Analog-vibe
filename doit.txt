task 1
Leggi `crates/greg_gui_core/src/lib.rs` (tutto il file).

Obiettivo: rendere `greg_gui_core` **100% a prova di crash di default ("Zero-Crash by Design")** per tutti e 18 i plugin CLAP/VST3, senza dover passare variabili d'ambiente manuali:

1. **Rilevamento Automatico dell'Ambiente Grafico (`is_gui_supported()`):**
   - Crea una funzione privata `fn is_gui_supported() -> bool` chiamata all'inizio sia di `create_greg_editor` sia di `create_greg_editor_with_params`:
     - Se `GREG_FORCE_GUI=1` (o `true`) è impostato → restituisci `true` (permette test forzati della GUI anche su VM).
     - Se `GREG_NO_GUI=1` (o `true`) è impostato → restituisci `false`.
     - Se `DISPLAY` è vuoto o non impostato (es. sessione headless o Wayland puro senza X11) → restituisci `false`.
     - Se il sistema gira su hypervisor/VM noto (controllando `/sys/class/dmi/id/product_name` o `/sys/class/dmi/id/sys_vendor` per `VirtualBox`, `VMware`, `QEMU`, `KVM`, `Parallels` senza errore se il file non esiste) → restituisci `false` di default (così Reaper, Bitwig e Ardour in VM aprono subito l'interfaccia nativa della DAW al 100% stabile senza crash OpenGL/X11!).

2. **Barriera Anti-Panic Interna al Thread X11 (`window_thread`):**
   - Dentro la closure `cx` passata a `create_vizia_editor` (sia in `create_greg_editor` sia in `create_greg_editor_with_params`), avvolgi l'intera costruzione dei widget (`VStack` / `HStack` / `ParamSlider` / `Label`) in `std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| { ... }))`.
   - Se la costruzione dovesse mai generare un panic interno, intercettalo silenziosamente dentro il thread UI e mostra un semplice `Label::new(cx, "Analog-Vibe DSP Active (Fallback UI)")` invece di far abortire `window_thread` (che causerebbe `RecvError` in `baseview` e il crash della DAW).
   - Elimina ogni `.unwrap()`, `.expect()` o accesso diretto `[i]` sui parametri e sanitizza ogni valore meter con `if v.is_finite() { v } else { 0.0 }`.

3. **Compilazione Release, Deploy & Push:**
   - Esegui `cargo test -p greg_gui_core` e `cargo build --release --workspace` (0 errori, 0 warning).
   - Copia tutti e 18 i `target/release/libgreg_*.so` in `~/.clap/Analog-vibe/greg_*.clap`.
   - Esegui `git add -A && git commit -m "[GUI Core] Blindatura Zero-Crash by Design: auto-detection VM/Wayland + catch_unwind interno al thread UI" && git push`.
