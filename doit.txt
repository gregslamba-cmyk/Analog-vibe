`[warn] parameter Input did not accept 0; current value is 0.5`
`[warn] parameter Ratio did not accept 2.25; current value is 0`

Correggi `tools/clap-validator-host/src/main.rs`:
1. Salva `info.cookie` da `clap_param_info` per ciascun parametro e passalo esattamente dentro `clap_event_param_value.cookie`.
2. Invia i valori dello sweep in scala **normalizzata `[0.0 .. 1.0]`** (es. `0.0`, `0.25`, `0.5`, `0.75`, `1.0`) o mappando `(val - min) / (max - min)` prima di inviare `CLAP_EVENT_PARAM_VALUE`, verificando con `params.get_value()` che il parametro accetti davvero il nuovo valore senza `[warn]`.
3. Compila solo `-p clap-validator-host` (`cargo build --release -p clap-validator-host`) e verifica su `target/release/libgreg_76.so` che i warning `did not accept` spariscano completamente!
